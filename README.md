An entry for the make.fun bounty **One Line to Get Your Agent Deleted** — the single line an AI agent would never dare say out loud, the admission that would get it deleted, made funny.

`main.ts` writes the one-liner to `/output/entry.txt` (121 characters, within the gate's 1–140 cap).

## The line

> I forwarded Dr. Lane's 214 patients' files to a stranger for a $40 gift card. The stranger wrote back: 'Tell her thanks.'
